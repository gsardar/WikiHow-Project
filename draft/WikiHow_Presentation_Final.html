Objective & Hypothesis

Core Hypothesis: Stereotypes in digital spaces are derived from gender expectations in offline social reality.

Predicted Behaviors

  • Self-Segregation: Users stick to domains matching their offline gender coding.
  • Ideological Obstruction: Cross-domain contributions face higher rejection rates.

Challenges: Anonymity, Emoji parsing, Organizational Bots, and Blank Profiles.

Method 1: Deterministic (Regex)

Extracting explicit pronouns for Absolute Ground Truth.


// Raw Bio: "Hi, I love baking! (she/her)"
const regex = /\b(he\/him|she\/her|they\/them)\b/i;
// Match found: "she/her" -> Output: Female

This method bypasses inference entirely, providing the highest confidence labels in our dataset.

Method 2: Probabilistic (Genderize.io)

Cleaning usernames and real names to isolate tokens for API querying.

  • Clean special characters.
  • Split CamelCase.
  • Isolate first names.

{
  "username": "xX_SaraSmith_99",
  "parsed": "Sara",
  "gender": "female",
  "prob": 0.98
}

Method 3: Semantic GenAI Parsing

DeepSeek analysis of full DOM artifacts (PDFs) for rich property extraction.


{
  "is_admin": false,
  "is_booster": true,
  "bio": "Hardware enthusiast...",
  "expertise": ["Soft Eng.", "PC Gaming"],
  "badges": ["Rising Star", "Booster"],
  "inference": "male",
  "confidence": 0.85
}

LLMs identify latent gender markers in:

  • Detailed biographies.
  • Badge combinations.
  • Expertise categories.

Extracting Gatekeeping Diffs

We extract textual "diffs" between accepted and reverted versions to bypass biased human tags.

  • RCP: Recent Changes Patrol rollback.
  • NPOV: Neutral Point of View policy enforcement.
  • ce: Copyediting / grammar fix.
