# Mapping WikiHow Authority Tiers

This mapper standardizes the heterogenous user groups of WikiHow into a 4-Tier Authority Continuum for trend analysis.

## Role Hierarchies

| Tier | Category | WikiHow Internal Groups | Social Ranks |
| :--- | :--- | :--- | :--- |
| **4** | **Executive** | `bureaucrat`, `checkuser`, `staff` | Board, Staff, Senior Admins |
| **3** | **Admin** | `sysop` | Administrators |
| **2** | **Gatekeeper** | `new_article_booster`, `QG` | Boosters, Quality Guard |
| **1** | **Service** | `welcomer`, `translator`, `answer_patroller` | Welcomers, Patrollers |

---

## Standardization Mapping

- `sysop` -> **Administrator**
- `new_article_booster` -> **Booster**
- `featured_author` -> **Featured**
- `QG` -> **Quality Guard**
- `welcomer` -> **Welcomer**
